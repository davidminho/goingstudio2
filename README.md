# Going Studio

Going Studio's production website, built with Next.js and Payload CMS.

## Local development

1. Copy `.env.example` to `.env`.
2. Set `DATABASE_URL` to a PostgreSQL database and add a secure `PAYLOAD_SECRET`.
3. Install dependencies with `npm install`.
4. Start the site with `npm run dev`.
5. Open `http://localhost:3000/admin` and create the first administrator.

The public site continues to render its bundled content if the database is unavailable. Once
Payload is connected, run `npm run seed` to populate the editable site settings, services and
projects.

## Production environment

The Vercel project requires:

- `DATABASE_URL` — persistent PostgreSQL database
- `PAYLOAD_SECRET` — long random secret
- `NEXT_PUBLIC_SERVER_URL` — canonical production URL
- `BLOB_READ_WRITE_TOKEN` — generated by a Vercel Blob store
- `CRON_SECRET` — long random secret for scheduled Payload jobs

Run `npm run build` before deployment. Payload Admin is available at `/admin`.
